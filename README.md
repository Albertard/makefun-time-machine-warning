# Funniest Time Machine Warning Label

A program that writes a single warning label for a time machine to
`/output/entry.txt`. Built for the make.fun competition **"Funniest
Time Machine Warning Label"**
(`u-eager-stork-81-9647-funniest-time-machine-warning-f8add151`).

## The warning label

> WARNING: Your grandfather is load-bearing. Do not remove.

57 characters. The joke turns the grandfather paradox into a piece of
structural engineering: grandad is not a person here, he is a
load-bearing wall, and the safety notice treats removing him like
knocking out a support beam. The surprise lands in the last two words
— "Do not remove" — after the reader has already pictured a warning
sticker on a machine that treats ancestry as architecture. It keeps a
straight face throughout, phrased as a genuine safety notice, and
wastes no words.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
